# ARRAY

- **Collection of similar data types**
- **Fixed size**
- **Index starts from 0**
- **Memory is allocated in contiguous memory locations** (continuous memory location means memory is allocated in a
  sequence)
- **Array is a reference type**

> **Note:** When we declare the array some garbage value is present initially but when we declare globally array is
> filled with the 0's .

> **Note:** If we declare the array inside the main the max `size will be 10^6` but globally it will be `10^7`.

## Array in Java

### Declaration of array in Java

```java
int arr[] = new int[5]; // declaration of array

int arr[] = {1, 2, 3, 4, 5}; // declaration and initialization of array
```
